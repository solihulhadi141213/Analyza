# Analyza

## Deskripsi Aplikasi
Analyza adalah Aplikasi microservice berbasis web untuk pelayanan laboratorium pada SIMRS rumah sakit. 
Aplikasi ini dirancang untuk dapat terintegrasi dengan SATUSEHAT sehingga arsitektur data menyesuaikan standar FHIR.

## Fitur
 1. Dashboard
 2. Pengaturan
 3. Aksesibilitas
 4. Koneksi
 5. Referensi
 6. Pelayanan Pemeriksaan
 7. Laporan
 8. Log Aktivitas
 9. Dokumentasi
 10. Profil Pengguna

## Teknologi yang Digunakan

 2. JavaScript
 3. HTML5
 4. CSS3
 5. Bootstrap 5 
 6. mdb-ui-kit 8.2.0
 7. JQuery 3.7.1
